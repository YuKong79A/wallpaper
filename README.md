# Wallpaper Collection

一个按配色方案整理的桌面壁纸收藏，适合搭配 Hyprland、Noctalia、Waybar 以及各类终端主题使用。

目前共收录 **2,038 个壁纸文件**，覆盖 19 个主题目录。

## 获取仓库

```bash
git clone https://github.com/YuKong79A/wallpaper.git
cd wallpaper
```

仓库体积较大，也可以使用浅克隆减少下载历史：

```bash
git clone --depth 1 https://github.com/YuKong79A/wallpaper.git
```

## 目录结构

```text
.
├── README.md
└── Wallpapers/     # 按配色方案分类的壁纸
```

## 使用方式

从 [`Wallpapers/`](./Wallpapers) 中进入喜欢的主题目录，将图片设置为桌面背景即可。使用壁纸切换器时，可以直接把对应主题目录配置为壁纸来源。
